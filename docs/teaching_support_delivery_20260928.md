# 教学支持与外部演示交付

## 当前可操作内容

- 教师在视频复核中记录回应媒介、音频质量、非言语发声和说话人确认。
- 未确认说话人的发声标为场景级信息；新增音频字段不改变评分算式。
- 教学支持页检查学校、上传、处理、身份与复核准备情况。
- 教师按支持需求选择建议；保存本课亮点、下次调整和后续观察，采用版本校验。
- DeepSeek只提供配置状态和白名单预览，不联网。服务端预留环境变量为 `REHAB_DEEPSEEK_API_KEY`、`REHAB_DEEPSEEK_MODEL`，不要把密钥放前端或文档。
- 外部网关增加单课、同课汇总及教学支持路由，保留邀请与账号两层验证。

## 未完成及边界

- 真实学校视频准确率与公平性验证未完成；软件测试不代表教育测评有效性。
- 不是按诊断自动生成干预；建议由教师按IEP与支持需要选择。
- 音频新字段由教师复核，不是自动非言语发声分类、声纹识别或医学诊断。
- 教师逐课改进是自评记录，未建立经验证的因果效果评价；科研导出和研究授权仍需另做。
- DeepSeek实际服务端调用、输出校验、超时回退和数据授权仍待实施。
- 不通过抬高总分或保底机制让教师得高分；保持缺失证据不等于零分。
- 未处理暂停的新增三名学生资料。
