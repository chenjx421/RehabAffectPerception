# v3.7 发布说明（2026-10-27）

## 本轮目标

把 Demo1 的课堂状态内容层恢复到通用人物跟踪管线上。保留任意视频的自动人物检测，不恢复 Demo1 的写死 ROI。

## 恢复的内容

- **五种状态**：参与、注意力下降、困惑·停滞、成人干扰下不确定、无法判断。
- **每段建议**：屏幕提示、语音提示、是否需要教师确认；本版本明确不含机器人动作。
- **关键片段**：每个时间片按风险优先级挑出复核点（困惑 > 成人干扰 > 注意力下降 > 参与），最多 6 个。
- **状态汇总**：每个人物的状态计数、占比和需教师确认的片段数，写入 `state_summary`。
- **个人报告**：按状态分布、关键片段和建议重写，保留原有边界说明。

## 判定输入

| 信号 | 来源 | 说明 |
| --- | --- | --- |
| 人物局部变化 | 固定座位区域逐秒画面差 | 主信号，与 Demo1 的 target motion 同源 |
| 相邻区域活动 | 座位外扩成环、抠掉本人区域后的画面差 | Demo1 的成人干扰项，用于识别教师/同学靠近和遮挡 |
| 课堂声音 | 已抽取的音频能量窗口 | 只有课堂级活动，不定位到个人 |
| 画质 | 清晰度与亮度 | 低画质时下调置信度 |

判定顺序与 Demo1 一致：持续变化 → 参与；相邻区域活跃且本人安静 → 成人干扰；本人安静但课堂有声音 → 困惑·停滞；本人长时间安静 → 注意力下降；证据不足 → 无法判断。

## 输出字段

窗口新增：`state`、`state_zh`、`interpretation`、`recommended_action`、`adult_interference`；原有 `movement`、`score` 保留为画面变化参考值。
人物新增：`key_moments`、`state_summary`；`student_state` 与 `state` 一致。

## 兼容与升级

- 版本号 `simple_student_seats_v3_7`，媒体缓存版本同步更新。
- 旧 v3.6 分析仍按旧版动作线索展示，不会把旧动作标签重新解释成注意力；访问旧任务时会触发一次重新分析请求。
- 部署后历史任务会在被打开时重新分析，不批量重跑。

## 已知限制

- 阈值沿用 Demo1 的经验值（参与 ≥0.35、成人干扰 ≥0.55 且本人 <0.22、困惑 <0.14 且课堂声音 ≥0.35、注意力 <0.18），需要用学校真实课堂视频校准。
- 课堂声音无法定位到学生，只作情境参考；成人干扰依赖画面，不识别具体身份。
- 状态是教学复盘线索，不是诊断、成绩或注意力测评结论。
