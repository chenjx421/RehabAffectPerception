# 《从会回答到会行动》PPT 生图提示词

## 一、课程定位

- **课程名称：** 从会回答到会行动
- **英文小标题：** From Answers to Actions
- **课程主题：** 人工智能、具身智能与助残机器人
- **授课对象：** 国际学校高中生
- **课程时长：** 90 分钟
- **建议页数：** 24 页
- **授课语言：** 中文主讲，必要专业术语保留英文

这不是双语课。英文只用于帮助学生认识常见专业词汇，不要求教师连续使用英语讲解。

## 二、语言使用规则

1. 每页标题以中文为主，英文仅作为小号副标题，复杂页面可以不放英文标题。
2. 每页最多出现 1—3 个英文专业词，且必须同时给出中文。
3. 提问、案例对话、结论和课堂指令全部使用中文。
4. 专业词第一次出现时使用“中文（English）”，后续页面以中文为主。
5. 流程图使用中文主标签，必要时在下方补充小号英文词。
6. 教师只需要会读少数核心词，不需要用英语解释完整概念。

### 建议保留的核心英文词

| 中文 | 英文 | 使用建议 |
| --- | --- | --- |
| 人工智能 | Artificial Intelligence / AI | 重点保留 |
| 具身智能 | Embodied AI | 重点保留 |
| 输入、模型、输出 | Input, Model, Output | 第一次出现时保留 |
| 传感器 | Sensor | 机器人结构页保留 |
| 执行器 | Actuator | 机器人结构页保留 |
| 反馈闭环 | Feedback Loop | 第一次出现时保留 |
| 物体检测 | Object Detection | 视觉任务页保留 |
| 姿态估计 | Pose Estimation | 视觉任务页保留 |
| 语音识别 | ASR | 语音页保留 |
| 多模态感知 | Multimodal Perception | 融合页保留 |
| 人在回路 | Human-in-the-loop | 安全页可选 |

## 三、统一生图总提示词

每次生成页面时，先发送下面的总提示词，再发送对应页面的独立提示词。

```text
请生成一页面向国际学校高中生的 16:9 演示文稿页面，课程主题为《从会回答到会行动：人工智能、具身智能与助残机器人》。

语言要求：
- 中文是页面主要语言，也是教师的主要授课语言。
- 只在必要的专业概念旁保留简短英文，例如“具身智能 Embodied AI”。
- 每页英文专业词不超过 3 个。
- 课堂问题、案例对话、结论和活动指令必须使用中文。
- 不要生成大段英文，不要把课程做成双语课。
- 如果中文无法准确生成，请为文字留出整洁空白区域，后续在 PowerPoint 中手动添加。

视觉要求：
- 1920×1080，16:9 横向页面。
- 白色或浅冷灰背景，深灰文字，中等蓝色为主强调色，少量橙色表示互动、警示或不确定性。
- 风格简洁、理性、现代，适合 15—18 岁高中生。
- 使用清晰的科学示意图、工程流程图、真实可信的机器人场景或简洁的教育插画。
- 每页只突出一个核心问题，保留充足留白。
- 不使用霓虹赛博朋克、发光大脑、悬浮芯片、科技光圈、装饰性渐变球或幼儿卡通风格。
- 机器人应当安全、友好、结构合理；学生应当是高中生形象。
- 助残场景保持尊重，不把残障或情绪问题表现成悲情故事。

版式要求：
- 中文主标题置于页面上方，英文小标题可放在其下方，字号明显更小。
- 页面文字控制在 3—5 个短点。
- 不生成品牌标志，不增加提示词中未指定的文字。
- 图中流程与标签应清晰，适合教室投影。
```

**生图提示词**

```text

中文主标题：“人工智能怎样完成一次判断？”
```

## 五、教师实际需要掌握的英文

现场只需自然读出以下词汇，后续解释全部使用中文：

1. AI：人工智能。
2. Embodied AI：具身智能。
3. Input、Model、Output：输入、模型、输出。
4. Sensor：传感器。
5. Object Detection：物体检测。
6. Pose Estimation：姿态估计。
7. ASR：语音识别。
8. Multimodal：多模态。

不熟悉的词可以直接读中文，不影响课程完整性。

## 六、生图和制作建议

1. GPT 生图容易把文字写错，建议主要生成版式、场景和示意图，标题与正文在 PowerPoint 中手动添加。
2. 第 4、9、11、12、16、19、22 页是知识结构图，最好使用 PowerPoint 形状重新绘制，保证术语准确、文字可编辑。
3. 第 1 页生成后，将封面图作为后续场景的人物和机器人参考图，保持整套 PPT 视觉统一。
4. 第 10、13、14、17、18、20、24 页尽量沿用同一台机器人和相同学生形象。
5. 页面中的英文始终小于中文字号，不让学生误以为课程需要全英文听讲。
