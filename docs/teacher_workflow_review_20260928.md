# 教师使用流程复盘

## 本轮已落地

1. 片段复核与原视频放在同一页面，桌面左右对照，窄屏上下排列，共用一个播放器。
2. 从播放器当前位置设置开始、结束时间；回看片段在结束时间自动暂停。
3. 沟通方式及音频信息默认折叠，评分继续可选，不要求没有证据的维度必须填满。
4. 沿用同一教学目标新增记录，只带入学生、日期、目标、条件和达成标准；清空回应、分数、证据与复核状态。
5. 清空表单、切换编辑记录与刷新前确认未保存修改；离开页面触发浏览器原生提醒。不在浏览器长期保存学生草稿。
6. 教师可筛选全部、待复核/待重确认、已复核记录。
7. 课程列表按名称与文件名搜索，处理状态转成中文，增加上传入口。
8. 本课资料、身份对应和教学支持入口在手机也能看到。

## 尚未完成：影响真实试点的事项

| 场景 | 目前边界 | 建议下一步 |
| --- | --- | --- |
| 上传一整节课后直接得到分析 | 目前以媒体证据与教师观察为主；不是成熟的自动掌握程度评分 | 先接入有时间戳的互动候选证据，并单独验证漏检、误归属与复核耗时；允许拒答，不让模型直接定分 |
| 不同机位、遮挡后持续认人 | 单帧绑定不等于可靠的全程身份追踪 | 保留人工修正，加入片段级追踪与身份冲突队列；低置信度中断归属，不自动移交给另一学生 |
| 听不清、多人同时发声 | 已能记录采集质量与发声，尚无可靠的自动说话人和非言语发声分类 | 先测试教室拾音覆盖，再增加事件候选时间戳；教师确认声音来源，未确认保留场景级 |
| AI辅助解释 | DeepSeek只有状态和白名单预览，未联网 | 服务端密钥、最少必要证据、输出格式与引用校验、超时回退、教师确认后发布 |
| 下节课直接接着上节目标 | 当前沿用目标仅限当前表单，非完整课程模板库 | 建立教师可确认的IEP目标模板与跨课选择；旧观察不能当新证据复制 |
| 多教师在同一学校协作 | 当前主要按账号隔离 | 明确校级授权、班级成员与复核责任，再实现可撤销共享和冲突处理，不能简单取消隔离 |
| 稳定地发给学校长期使用 | 临时隧道依赖电脑在线，部分网络DNS异常 | 公司控制的域名、HTTPS、长期服务器、任务队列、监控、备份与恢复演练 |
| 数据到期管理 | 原视频60天；结构化记录当前730天，到期仅提醒人工处理 | 与学校分别确认各类保留期限，增加可审计的归档、删除及失败告警，不能把所有数据一律永久保存 |
| 科研与教学有效性 | 软件通过测试不代表测评有效 | 同一目标和支持条件下积累教师双人复核样本，检验一致性及纵向可比性；研究使用单独授权 |
| 手机号会员与付款 | 代码存在服务未配置分支，本轮未确认线上服务已开通 | 正式采购和配置短信/支付服务，走沙箱验收、订单状态与失败恢复；不是试点必备项 |

## 建议试用方式

由一名未参加开发的教师，使用有授权的短视频完成上传、绑定学生、记录一次回应及导出报告。记录每步耗时、求助次数、撤回操作、上传失败和误归属。然后用完整课堂重复。不要把合成测试数据当作真实课堂能力评估。

本轮未宣称完成自动识别升级、已验证权重或长期公网部署；未处理暂停的新学生资料。
