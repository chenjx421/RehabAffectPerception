# 学生评课评分与长期测量契约

这份契约对应 2026-09-15 的整改要求，供 Demo2 的前端、报告、数据存储和后续模型共同使用。

## 评分标准

每次课按 0--10 分记录，**6 分为及格**。分数描述明确出现的学习机会，不把“看起来在参与”、表情或动作直接当成掌握。

| 分数 | 统一含义 |
| --- | --- |
| 0 | 没有形成可评分的学习机会，或没有可核对证据 |
| 2 | 需要完整示范或持续协助，尚不能独立复现 |
| 4 | 部分完成，需要重复提示、拆分任务或明显协助 |
| 6 | 达到本节目标的最低要求，可在简单提示下完成 |
| 8 | 大多独立且稳定，偶尔需要普通提示 |
| 10 | 独立、稳定，并能迁移到相似的新材料或新情境 |

综合分使用四个维度，权重固定为：正确性 35%、独立程度 30%、重复一致性 20%、迁移 15%。缺少某个维度时只对已观察维度重新归一化；未观察不能按 0 分计入。观察机会少于 2 次时只能显示“未观察/证据不足”，不能判定及格。

每条结论必须保留：学习机会次数、实际观察次数、视频时间段、证据来源、教师复核状态和置信度。系统初评不等于教师最终评分，也不用于学生之间排名。

## 长期测量页面

学生个体页提供四个时间粒度：每次课、每周、每月、滚动 60 天。页面同时展示综合分、四维分数、及格线、有效课次数和证据不足次数。趋势图只连接有效评分点；缺失或未观察记录显示为空档，并给出原因。

群像页只展示班级支持情况和课程阶段分布；点击某个学生后进入个体页，避免把群体均值误读成个体结论。

## 图文报告

千字报告由“指标卡 + 趋势图 + 关键时间段 + 简短文字”组成。每张图必须标注时间范围、单位、样本数和“系统初评/教师已复核”。正文只解释图中可见变化，不用没有证据的因果词。

## 采集、存储和内测账号

视频与音频采集需要硬件可用性检查、格式/时长上限、任务状态和失败原因；采集失败不能生成评分。原始媒体按 60 天策略管理，结构化记录和报告保留期单独配置，删除前提醒并保留审计记录。

当前内测账号为四个学校上传账号 `t1`--`t4`，另有一个独立的公司管理员账号 `admin` 用于后台数据浏览和通道管理。账号之间按通道隔离，管理员不能代替学校确认学生身份。
