## 验收项

- [x] 上传完整后登记排队，后续解码不占用上传请求。SHA-256校验仍在最后分片请求中执行。
- [x] 单机同库仅一个分析进程，任务进度、失败原因与重试次数持久化。
- [x] 整片实际解码，1 fps 采样、20 秒窗口能对应原片，末段覆盖准确。
- [x] 音轨提取及覆盖范围明确，音轨延迟和无音轨不会变成虚构文本。
- [x] 所有者和管理员可查看自己的权限范围，其他账号不能读原片、音轨或结果。
- [x] 原片和派生音轨/图像共同遵守60天保存与到期清理。
- [x] 点击片段可定位原视频，桌面和390px页面可用。
- [x] 新处理输出不含虚构身份、情绪、作答或掌握度结论。
- [x] 原有课堂分析、档案、登录和四通道流程通过回归。

## 尚未实施的部分

本轮完成的是媒体证据处理，不是整个三周方案。教师确认座位ROI、自动人物跟踪、VAD/ASR、逐字稿、作答判断和新视频千字报告仍未实现；历史Demo报告没有套用到新任务。

时间窗是原片索引，不是单独编码的短视频；原片播放仍依赖浏览器编码兼容，尚未实现代理转码。下一步优先接入中文转写及教师可纠正的时间戳记录，再建立学习机会与作答统计。

运行依赖仍为本地FFmpeg/ffprobe、OpenCV、NumPy；未接外部大模型API，未上传校方媒体到云端。AI岗位原课验证产生的额外临时帧图和音轨已在主控验收后清理，仅保留技术JSON索引；正式上传任务的派生媒体仍受业务60天规则管理。本地截图包含校方原课，需要单独管理，不能视为已脱敏或可公开发布。
