# 课堂视频分析原型执行方案

**RehabAffectPerception | 2026年9月8日**

实施进度：已接通真实上传队列、整片媒体处理及受保护视频证据页。完整原课HTTP验收与统一回归见 [本轮验收记录](D:/GIT/RehabAffectPerception/docs/media_pipeline_iteration_20260908_zh.md)。本文件以下“产品现状”保留为开发开始前的基线，不代表最新完成状态；ASR、教师目标复核与新课学习报告仍按后续步骤推进。

## 一、产品现状与建设目标

平台已完成登录、学校信息、注册及隐私界面，具备静态预览和本地服务。学校信息目前仅为业务元数据，尚不构成租户隔离；正式应用的公网部署尚未开展。

已有离线分析能够解码课堂视频、提取固定座位区域的运动及质量特征，并生成时间线和演示报告。但新上传流程目前只完成文件接收与视频预检，尚未接通真正的分析和报告后台任务。预检最多抽取四十帧，不能据此判断学生行为或学习成效。[上传预检实现](D:/GIT/RehabAffectPerception/src/rehab_affect/student_record_store.py:1938)

离线演示中的部分掌握度由历史等级、参与信号和规则机会数计算，不是逐次作答测量。后续必须将这些演示结果与真实学生记录分开，不能以“待复核”标签替代证据。[离线测量](/D:/GIT/RehabAffectPerception/src/rehab_affect/seewo_multi_student_demo.py:143)、[演示评分](/D:/GIT/RehabAffectPerception/src/rehab_affect/seewo_multi_student_demo.py:571)

本阶段目标是形成“上传一节课、找到原始片段、教师确认表现、生成证据摘要”的可用闭环，而非自动判断全班学生是否学会。

## 二、市场参照与产品价值

希沃提供课堂采集、分析报告及人工听评课关联，适合作为学校授权录像的来源；其官方所述课后约十分钟出报告，不应直接作为本产品时效承诺。当前不假设已经获得希沃开放接口或商业合作。[希沃官方说明](https://help.seewo.com/edulyse/v5tJFMYMbm)

Edthena AI Coach 围绕录像时间戳评论、反思和教学行动组织教师辅导；TeachFX 利用课堂音频提供话语模式反馈。可借鉴的是教师回看、修改与分享的控制权，不是用话语时长或动作多少代替学习评价。[Edthena](https://www.edthena.com/ai-coach-for-teachers/)、[TeachFX](https://teachfx.com/)

特殊教育的个体进展应围绕明确目标、客观测量及重复记录。IRIS Center 的进展监测方法可用于设计目标表，但不代表某视频模型已经具备测量能力，也不构成中国学校的法律要求。[IRIS Center](https://iris.peabody.vanderbilt.edu/module/iep01/cresource/q3/p09/)

因此，产品首先解决“证据难找、判断难复核”的问题。以上为官方公开功能及方法参照，尚无本校竞品对照试验，不宣称识别准确率或教学效果领先。

## 三、三周原型范围

采用单机、一个后台分析进程、一个课程、三名重点学生和固定机位；每次处理一条录像，任务排队执行。必要输入包括授权录像、教师确认的座位区域、一至两个观察目标及对应任务标准。

必做范围为媒体检查、基础区域特征、中文语音转写、时间戳定位、人工事件标注、基本复核记录和单课摘要。自动说话人身份识别、多机位同步、精细动作识别、跨课趋势、租户隔离及生产运维不列入三周验收。VLM 短片分析仅作为可选验证，不影响基础交付。

排期按十五个工作日估算，需后端与模型工程投入、测试支持及教师定期复核。素材授权、课程规则或开发环境未到位时，应调整开始时间或减少可选功能，不压缩证据与权限检查。

## 四、执行安排

### 第一周：上传接入真实媒体处理

第1至2天，确定任务与文件关系，沿用现有数据库登记待处理任务。单个 worker 顺序领取，保存阶段、错误和重试次数；按文件及配置版本避免重复执行。上传成功与分析完成分别展示。

第3至4天，接入媒体元数据、流式解码、音轨提取及固定座位区域采样。生成按任务保存的代理视频和时间戳索引，保留原文件标识；不覆盖离线演示缓存。换座或遮挡时暂停身份关联，由教师确认。

第5天，验证有效录像、无音轨、损坏文件、重复提交和进程中断。输出必须能回到实际画面；失败任务显示原因，不填充合成课堂结论。周交付为一个新上传视频的可回放处理结果。

### 第二周：语音转写与时间戳复核

第6至7天，接入一套中文 ASR 和语音活动检测，保留逐段起止时间；课堂远场转写作为候选文本，允许错误和缺失。教师手动标记角色或学生，齐答、代答及不明声源保留未知。

第8至9天，提供“视频、逐字稿、目标表”联动界面。教师可定位并增删片段，记录是否出现任务机会、学生回应、正确性及提示方式。保存复核人、时间和修改版本，不要求模型自动识别整套教学行为。

第10天，用同一课程中的保留录像检查时间定位、转写错误和身份误归属；同时抽查无候选片段，避免只看系统找到的内容。周交付为教师能够纠错、保存并重新打开的证据记录。

### 第三周：目标记录与单课摘要

第11至12天，与教师确认一至两个目标的完成标准，记录真实学习机会和允许的提示条件。对语言表达困难的学生，允许实物操作、图卡或教师直接观察作为补充证据，不因缺少语音就判未完成。

第13天，完成确定性次数统计和模板摘要。每项结论关联片段或明确的教师观察记录；未确认内容显示为草稿，正式输出须经教师确认。文本模型仅作可选措辞整理，不决定次数或等级。

第14至15天，完成同一课程、三名学生的闭环演示及回归测试，记录教师复核时间、转写字错误率、错误归属、无法判断比例和处理成本。周交付包括原型、匿名样例、验收记录及下一阶段问题清单，不等于完成生产平台建设。

## 五、证据规则与技术选择

一次记录须包含课程、任务、学生或未知身份、目标、证据起止时间、处理版本和复核状态。机会分为有、无、未知；表现分为独立正确 I、提示正确 P、错误或未完成 E、证据不足 U。

有效机会 N=I+P+E，呈现 I/N、P/N、E/N，并另列 U 和无机会数。N=0 时显示暂无可评分机会，不显示零分。看起来专注不等于掌握，提示后完成不等于独立完成；教师调整后的变化只能称观察关联，不能直接宣称因果。

基础处理采用 [FFmpeg/ffprobe](https://ffmpeg.org/ffprobe.html)；本地中文转写可验证 [FunASR](https://github.com/modelscope/FunASR)。需要人员检测或姿态线索时，可评估 [Ultralytics](https://docs.ultralytics.com/modes/track/) 或 [MediaPipe](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker)，但不以其通用能力保证课堂效果。固定座位原型不依赖完整自动追踪，软件和预训练权重许可分别核查。

可选 VLM 仅描述获批准短片中的可见事件，并返回时间段及不确定原因；音轨另走 ASR，不能默认视觉模型听懂了视频声音。结构化报告必须校验证据引用和数字，字幕及转写不能作为系统指令；模型无权自行发布或写入学生主档。[阿里云视觉接口](https://help.aliyun.com/zh/model-studio/vision)、[录音识别接口](https://help.aliyun.com/zh/model-studio/paraformer-recorded-speech-recognition-restful-api)

官方价格核对口径为北京地域、常规按量、无缓存：Qwen3-VL-Plus 单请求输入不超过32K时，输入/输出为1/10元每百万 token；Qwen-Plus 非思考且输入不超过128K时为0.8/2元；Paraformer-v2 非实时为0.00008元/秒。不扣免费额度，不将长输入阶梯或思考输出混用。[百炼价格](https://help.aliyun.com/zh/model-studio/model-pricing)

以35分钟、一条音轨为例，可选方案假设十二段各二十秒、每秒一帧，每帧256个视觉 token，每段另加800个输入、300个输出 token；文本报告输入8,000、输出1,500。每帧 token 只是估算参数，实际以 usage 和账单为准。

## 七、界面、部署及验收

教师界面采用白底、蓝色导航、浅灰分隔和紧凑表格，不做卡通化。课程页显示上传、处理、复核三个状态；复核页保持稳定比例播放器、时间线、逐字稿和目标表单。手机端按视频、证据、表单排列，避免遮挡和长文本溢出。

原型优先本机运行。校园网访问需确认监听地址、路由、防火墙及安全传输；公网域名还需服务器、DNS、TLS、备案适用性和运维条件，均不属于本轮部署成果。真实资料只限获授权人员使用；学校元数据不能替代对象级授权，更不能作为跨校开放依据。

原片、数据库和凭据不得公开。云调用须单独批准数据范围、地域、供应商留存及删除条款；不能为了接口取文件而公开上传目录。保存期应覆盖音轨、代理和备份，公开展示使用独立匿名样例。[个人信息保护法](https://wb.flk.npc.gov.cn/flfg/PDF/f67af9f12e1b4c83a998cf5a876ce0e4.pdf)、[备案规定](https://www.miit.gov.cn/gyhxxhb/jgsj/cyzcyfgs/bmgz/xxtxl/art/2024/art_84a0cfa0ebd049bbbe751dca9a008e56.html)

验收重点为：新上传能生成真实处理记录；时间戳能定位同一原片；教师修改可保存并反映到统计；无证据不产生掌握结论；未经授权不能取得媒体和结果。试点发现安全缺口时停止真实数据访问，不以原型名义豁免。
