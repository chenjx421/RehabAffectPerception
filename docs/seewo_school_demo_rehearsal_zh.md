# 辅读学校 Demo 现场复习提纲

## 一句话定位

这是一个利用学校已有 Seewo 课堂视频、课堂声音、评课报告和学生个体评估资料，持续追踪单个学生课堂状态，并生成低刺激课堂支持动作的原型系统。

系统不做医学诊断，不评价教师个人能力，也不直接替代教师干预。它负责筛选值得复核的时刻、说明证据、提出支持动作，再由老师确认。

## 演示前准备

1. 双击项目根目录的 `start_school_demo.cmd`。
2. 确认浏览器打开 `http://127.0.0.1:8791/seewo_student_demo`。
3. 保持电脑接通电源，关闭系统通知，不在现场强制重新分析整段视频。
4. 使用本地缓存结果演示，学校网络中断也不影响页面运行。

## 3 至 5 分钟演示顺序

### 1. 先讲输入

指向左侧“学生画像与数据来源”：

- Seewo 导出的约 38 分钟课堂视频，包含课堂声音。
- Seewo 评课报告，用来提供课程名称、课堂节奏、抬头率、参与度等背景。
- 一张目标学生参考图和人工 ROI，用于明确本次追踪对象。
- 匿名化 IEP、认知、语言沟通和运动能力摘要，用于限制提示方式。

推荐话术：现阶段不要求学校部署新摄像头，先复用已有课堂资料验证价值。原始资料由本地程序读取，当前不是自动连接 Seewo 后台。

### 2. 再讲整节课结论

指向中间“学生支持结论”：

- 视频被切成 77 个 30 秒窗口。
- 参与窗口约占 74%，用于建立该学生的个人课堂基线。
- 系统找到注意力下降、困惑/停滞和成人遮挡等候选窗口。
- 这些数字是机器筛选结果，不是学生标签，也不是医学结论。

推荐话术：价值不在于给整节课打一个分，而在于帮助老师快速找到值得回看的时刻。

### 3. 点击一个关键复核片段

先点击“01:00-01:30 疑似需要一步提示”：

- 说明系统同时参考目标区域动作、课堂声音、场景和画面质量。
- 右侧输出状态、置信度、底层证据和复核问题。
- 展示屏幕一步高亮、短句语音、机器人慢转向和老师端提醒。

再点击“01:30-02:00 成人靠近导致不确定”：

- 强调系统不会在遮挡情况下强行判断学生。
- 此时建议不触发机器人动作，交给老师观察确认。

### 4. 演示老师复核

点击“符合观察”“需要修正”或“不确定”之一。

推荐话术：老师不需要标注整堂课，只复核少量关键片段。复核结果以后可以进入学生个人数据库，成为轻量训练与个体化校准数据。

### 5. 展示长期追踪与教师效果

点击右侧“学生追踪”“个体档案”和“教师效果”：

- 学生追踪用于比较同一学生在不同课程、不同时间的变化。
- 个体档案用于记录有效提示、禁忌刺激和能力领域信息。
- 教师效果只衡量“本节课对该学生的支持效果”，不用于教师排名或绩效考核。

### 6. 最后落到机器人动作

点击“动作方案”或“完整 JSON”：

- 屏幕动作：弱高亮、只显示当前一步。
- 语音动作：短句、慢速、一次只给一个指令。
- 机器人动作：慢转向、轻微点头、等待或不动作。
- 老师端动作：提醒、复核和人工接管。

推荐话术：后续可通过 WebSocket 或 ROS2 把结构化动作发送给桌面机器人、教育小车或学生端屏幕。高影响动作必须经过白名单、安全控制器和老师确认。

## 明确的输入与输出

| 类别 | 当前 Demo | 后续落地 |
| --- | --- | --- |
| 视频输入 | 项目文件夹中的 Seewo 导出 MP4 | 校方授权后由教师手动上传，后续再评估平台接口 |
| 音频输入 | 直接从课堂视频提取音轨 | 可增加 ASR、语速、停顿和声音事件分析 |
| 报告输入 | Seewo 导出的评课 Word 文档 | 上传后自动解析课程背景字段 |
| 学生资料 | 本地匿名化 IEP 和能力评估摘要 | 每名学生建立权限隔离的个体档案 |
| 分析输出 | 状态时间线、关键片段、证据、支持指数 | 多节课趋势、教师复核闭环和模型训练数据 |
| 动作输出 | 屏幕、语音、机器人和老师端建议 | WebSocket/ROS2 接入真机或交互屏 |

## 校方可能追问

**这是实时监控吗？**

当前是课后离线分析 Demo，优先保证可复核和低风险。后续可以做准实时窗口分析，但不会一开始就自动干预学生。

**准确率有多高？**

当前是可解释特征原型，不能把页面数字当成最终准确率。需要教师复核关键窗口，积累标签后才能按学生、课程和状态计算 Precision、Recall、F1 与误报率。

**为什么不用精细表情识别？**

现有全景视频分辨率较低，精细表情和眼神判断不可靠。当前优先使用粗粒度动作、课堂声音、场景和历史资料，并明确输出不确定状态。

**是否会给学生贴标签？**

不会。状态只描述某个课堂时间窗口，档案用于支持策略，不用于医学诊断或公开排名。

**与 Seewo 有什么关系？**

Seewo 提供课堂视频和整体评课数据，本系统补充单学生时间线、个体档案、老师复核、跨课追踪和机器人动作输出，两者是互补关系。

## 当前边界

- 当前结果来自一个学生的一节课，只能作为初始基线。
- 74%、71/100 等数字是原型量化结果，现场应说明计算依据和使用边界。
- 原始学生视频、图片和评估资料不应脱离授权环境公开传播。
- 不承诺医学诊断、教师考核结论或完全自动化干预。
