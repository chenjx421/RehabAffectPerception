# 学校基础与情境复核

新建课堂评价默认选择“学校基础 + 情境复核”。旧记录保留原方案和已保存结果；未指定方案的旧 API 请求仍按 common 处理。

## 计算规则

- 适用于学校10项基本评价表，不强行映射15项原表。
- 保留学校逐项权重，每项10%，分类20% / 30% / 30% / 20%。
- 情境修正分留空时沿用对应学校分，不把空值当作零。
- 有改分建议，必须填写证据、应对及后续表现的理由和下一课建议。
- 复核前显示建议及其潜在总分影响，但不应用建议。
- 教师确认复核后，最终分为学校基础分加逐项权重乘以已复核单项分差。
- 既不设置高分保底，也不限制有充分依据的低分；不自动按事件类型扣分。
- 缺少学校基础分时不能修正该项，基础缺项时不生成完整总分。
- 页面修改评分或证据后取消原复核勾选，需重新确认。后端保存原始建议、复核状态和版本。

## 使用步骤

进入 /demo2/evaluation，新建记录，选择基本评价表，录入学校分。普通项目无需再次填写增强分。需要修正的项目填写建议分、片段时间、教师应对、学生后续表现和下次教学建议。先预览或保存待复核记录，确认后再勾选复核并保存。

例如合成案例学校总分8.00，某项由6分建议改为8分：未复核仍8.00；复核后8.20。分差0.20来自该项10%的权重，不来自隐藏的保底或额外加权。

## 边界

系统不能自动判断理由是否真实或充分，当前由教师复核。不能仅因学生障碍、非口语回应、活动中断或音视频采集不足扣分。安全事件不由总分定性，不代表已经实现独立安全事件识别、上报或处置流程。

本次没有接入自动视频评分或DeepSeek，也未新增科学有效性结论。后续应补证据片段关联、独立复核和分歧记录、安全事件独立流程，再用普通课堂及特殊情境案例校准评价的一致性。
