# 安全事件人工核查

## 已实现

- 入口：课堂评价导航的“安全核查”，或单课工作台的“提交安全核查”。
- 提交：选择已处理的视频、设定起止秒数，填写客观观察和现场措施。支持播放器当前位置设点；后端校验视频归属、可用性及实际时长。
- 授权：提交者确认学校授权后，明确指定另一同校教师账号。没有核查账号时保持待指定，不伪造负责人。可撤销或重新指定。
- 范围：指定核查人能看这一条事件和关联完整原视频（包括音频），不是仅剪辑片段。界面明确披露，不授予其他档案或视频权限。
- 回看：默认回看事件前后各10秒，保留原视频播放能力。
- 结论：待核查、补充材料中、已核实、已排除、无法判断。只有指定核查人声明无利益冲突后能提交结论；提交者不可自行结案。
- 补充：新材料将状态置为补充材料中，旧结论仍保存在历史中。撤销或更换核查人会恢复待核查。
- 留痕：服务端版本校验防止覆盖，保存操作者、时间、授权对象、确认和说明；记录媒体读取、创建、变更和工作区访问审计。
- 保护：事件说明与处理历史通过现有加密资料保险库保存；公司管理员和未获授权者不能直接读取。学校归属变化后拒绝原授权访问。
- 保存：原视频不复制、不延长保存期；事件详情最多60天且不晚于原视频到期。事件接口访问时执行逻辑删除，尚未加入独立定时清理任务或备份介质擦除流程。
- 评分：不改变课堂评价、不自动扣分，不接入自动识别、外部模型或训练集。

## 使用前条件

提交人须有本校可播放、已解析时长的课堂视频；核查人须有另一同校账号。学校需明确授权、负责人和利益冲突处理安排，不能仅靠同校名称或一次勾选替代组织管理。演示并未自动给现有账号创建额外授权。

## 测试

安全核查、情境评分、公网网关及课堂分析相关测试合计98项通过，其中新增安全核查定向测试10项。浏览器使用隔离数据库和合成视频，验证提交、授权、核查人视频实际播放推进、结论保存、提交者不能结案、撤销后媒体拒绝访问、管理员403、320/390宽度无横向溢出。

## 后续边界

自动动作检测、声音筛选、自动上报、线下处置、自动关联扣分和学校级负责人认证尚未实现。下一步先核验学校授权组织结构和真实使用流程，再讨论二次复核、消息通知、定时清理和有限自动候选筛选。平台已发出的媒体字节无法远程收回，撤销阻断的是后续请求；不应向不适合接收原视频的人授权。

若现场有即时危险，须按学校既定安全流程及时处理，不等待平台核查。系统中“已核实”是授权核查人的记录，不是模型或司法认定。
