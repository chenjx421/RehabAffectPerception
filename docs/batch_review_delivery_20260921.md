# 同课多视频核准

## 使用入口

教师登录后，进入课堂复核页，选择页面顶部或左侧的“同课多视频汇总”。

同一账号、同一学校快照、相同课程批次号的视频会进入同一汇总页。没有批次号的旧任务只纳入当前视频，不自动猜测所属课堂。

页面分为视频列表、汇总数量和学生目标核准三个部分。手机也保留顶部入口。

## 已实现

- 根据上课日期、学生、目标、测量条件、达成标准及量表版本分组。同批次不同日期不作为同一节课合并。
- 保留每条原观察的来源视频、时间段、证据、原分数和机会数。可以返回单视频查看或修正。
- 多条记录不自动相加观察次数、不自动平均分数，即使原分数一致也要确认代表性。
- 教师选择一条已复核且身份有效的记录，填写理由并确认，作为该目标的本课结论。不是重新推断或合成学生成绩。
- 长期趋势使用相同核准规则：未核准的同课重复目标只保留一个空缺点，已核准后只计一次。
- 核准记录具有版本号和历史。源记录更新、撤销、身份失效或新增同组记录后，旧核准不再生效，需重新确认。
- 下载完整核准 JSON，支持打印汇总；其他教师账号和公司管理员无法读取本接口的学生原文。

## 当前边界

这次解决的是多视频证据组织、教师核准和重复统计问题，不是自动多机位人物匹配、自动理解教学活动或自动评分。不同上传账号的数据不混合。课程批次仍需上传时正确填写。

当前单视频千字报告继续描述单视频观察；本页另提供课程批次核准汇总，尚未把全部来源融合成新的千字叙述。长期趋势已采用批次核准结果。
