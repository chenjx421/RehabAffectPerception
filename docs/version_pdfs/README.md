# 版本 PDF 归档

这里保存 Demo1-Demo2 各阶段已经推出过的 PDF 版本说明、功能展示、交付材料和测试操作说明。

## 使用规则

- 目录名对应 `docs/demo_version_catalog_zh.md` 中的版本号。
- 同一版本只保留有明确日期、内容清晰、能说明该版本功能的一份或几份 PDF，不重复上传同一材料的所有渲染稿。
- PDF 是版本交付证据，不等于其中描述的每个功能都在最终云端主线中启用。
- 截至目前没有找到 V01、V03、V05、V06、V07、V12、V13、V17、V18、V19、V20、V21、V23、V24 的独立可公开 PDF，具体原因见公开归档清单。
- V17、V21、V23 的部分原始 PDF 包含公网入口、临时隧道或测试凭据，因此不直接上传；代码和不含凭据的版本说明仍然归档。
