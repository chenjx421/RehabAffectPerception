# 《从会回答到会行动》PPT 结构与逐页生图提示词

## 一、课程基本信息

- 课程主题：《从会回答到会行动：人工智能与具身智能入门》
- 副标题：以助残机器人为例，理解 AI 如何看见、听见、判断并作出回应
- 目标学生：国际学校高中生
- 课程时长：90 分钟
- 建议页数：24 页
- 课堂形式：讲解、现场投票、实物小车演示、案例分析、小组系统设计、成果展示

## 二、整套 PPT 的结构

| 阶段 | 页码 | 时间 | 内容 |
| --- | --- | --- | --- |
| 问题导入 | 1-3 | 0-10 分钟 | 从“我没事”引出机器判断的困难 |
| AI 基础 | 4-6 | 10-22 分钟 | 输入-模型-输出、训练与推理、置信度 |
| 具身智能 | 7-11 | 22-38 分钟 | 聊天 AI 与机器人、传感器、执行器、闭环、小车避障 |
| 机器人感知 | 12-16 | 38-55 分钟 | 图像分类、物体检测、姿态估计、语音识别、多模态 |
| 助残机器人案例 | 17-19 | 55-65 分钟 | 机器人定义、案例分析、安全响应等级 |
| 学生实践 | 20-23 | 65-85 分钟 | 系统设计挑战、任务卡、设计画布、展示评分 |
| 总结 | 24 | 85-90 分钟 | 核心知识回顾与离场问题 |

## 三、统一视觉总提示词

下面这段作为每次生图时的共同前缀。生成每一页时，把它和对应页面提示词一起发送给 GPT。

```text
请生成一页 16:9 横版高中生人工智能公开课 PPT，分辨率 1920×1080。

整套主题是“从会回答到会行动：人工智能与具身智能入门”，以助残机器人为主要案例。受众是国际学校高中生，因此视觉应该现代、理性、有科技感，但不能低龄化、卡通化或像儿童培训机构。

统一视觉风格：
1. 使用白色或非常浅的冷灰背景，深灰正文，蓝色为主要强调色，少量橙色用于风险、动作和互动提示。
2. 排版像科学博物馆展板或现代科技课堂，不使用商务汇报式的大量卡片，不使用大面积渐变、光球、霓虹、赛博朋克背景。
3. 每页只能有一个核心结论和一个主要视觉对象，画面留白充足。
4. 使用清晰的信息图、真实感机器人场景、简洁线条示意图或高质量 3D 教育插画。
5. 不使用虚构公司 Logo，不使用未经要求的品牌标志。
6. 中文必须为简体中文，标题短而醒目，正文尽量控制在 3-5 条，每条不超过 18 个汉字。
7. 文字区域必须清晰、平整、无遮挡，不能让人物、机器人或图形压住文字。
8. 不要自行增加提示词中没有的文字。
9. 所有页面保持相同标题位置、字体气质、蓝橙配色和页码样式。
10. 如果无法准确生成中文，请保留明确的标题和正文占位区域，不要生成乱码，后续将在 PowerPoint 中补字。

页面底部右侧放小号页码，底部左侧可以放极简章节标签。不要加入装饰性英文口号。
```

## 四、逐页内容与提示词

### 第 1 页：封面

**页面目标**

让学生立刻知道这不是普通 ChatGPT 科普，而是讨论 AI 如何进入机器人身体。

**屏幕文字**

```text
从会回答到会行动
人工智能与具身智能入门

以助残机器人为例
```

**讲师动作**

不急着自我介绍，先问：“你们觉得 ChatGPT 能自己走到教室门口吗？”

**生图提示词**

```text
生成课程封面。画面主体是一台现代但真实可信的助残服务机器人，位于明亮的学校创新实验室中，机器人面向一名高中生，旁边能看到摄像头、麦克风、轮式底盘等结构线索。构图简洁，机器人位于右侧，左侧保留大面积标题空间。

标题：
“从会回答到会行动”

副标题：
“人工智能与具身智能入门”

小字：
“以助残机器人为例”

整体像国际学校科技公开课，不要卡通，不要机械战斗风，不要复杂电路背景。
```

### 第 2 页：开场投票

**页面目标**

让学生主动发现“单一信息不足以判断人的状态”。

**屏幕文字**

```text
他说：“我没事。”

但他低着头、声音很小，
已经很久没有回应。

机器人应该相信什么？
```

**互动**

让学生举手选择：

1. 相信他说的话。
2. 相信表情和动作。
3. 继续观察并询问。

**生图提示词**

```text
生成课堂开场投票页。画面左侧是一名坐在课桌前的高中生，低头、姿态收缩，但不要夸张悲伤；右侧是一台小型服务机器人正在观察。画面中部展示三种信息来源的简洁线索：文字气泡“我没事”、低头姿态轮廓、声音波形。

标题：
“机器人应该相信什么？”

正文：
“他说：我没事。”
“但他低着头、声音很小，已经很久没有回应。”

底部放三个简洁选项：
“A 相信文字”
“B 相信表情和动作”
“C 继续观察并询问”

风格严肃但有互动感，不把学生画成明显患病或哭泣。
```

### 第 3 页：第一条结论

**页面目标**

完成开场问题的知识收束。

**屏幕文字**

```text
一个线索，不等于一个结论

文字 + 声音 + 表情 + 动作 + 任务过程
```

**讲解重点**

人的状态不是简单标签。机器人获得的是线索，不是真相。

**生图提示词**

```text
生成结论型信息图。中央是一台机器人，周围五个信息来源以线条连接到机器人：文字气泡、声音波形、人脸表情、人体姿态、任务进度条。所有线索汇入机器人，但机器人输出的是一个带问号的“可能状态”，而不是确定结论。

标题：
“一个线索，不等于一个结论”

底部关键词：
“文字 + 声音 + 表情 + 动作 + 任务过程”

视觉重点是多种证据共同判断，避免画成机器人直接扫描大脑或读取思想。
```

### 第 4 页：AI 的基本结构

**页面目标**

让学生建立最基本的 AI 工作模型。

**屏幕文字**

```text
人工智能怎样完成一次判断？

输入 → 模型 → 输出
```

**知识点**

- 输入可以是图片、文字、声音和传感器数据。
- 模型根据学到的规律处理输入。
- 输出可能是类别、位置、文字或动作建议。

**生图提示词**

```text
生成一个非常清楚的三阶段流程图，横向阅读：

左侧“输入”：图片、文字、声音波形、距离数据；
中间“模型”：一个简洁的人工智能处理模块，不画大脑芯片；
右侧“输出”：物体类别、位置框、转写文字、机器人动作建议。

标题：
“人工智能怎样完成一次判断？”

中央公式：
“输入 → 模型 → 输出”

底部小字：
“图片 / 文字 / 声音 / 传感器”
“类别 / 位置 / 文字 / 动作建议”

图形必须一眼可读，不使用复杂神经网络节点背景。
```

### 第 5 页：训练与推理

**页面目标**

用高中生能理解的比喻解释两个基本术语。

**屏幕文字**

```text
训练像刷题，推理像考试

训练：从大量例子中学习规律
推理：用规律判断新的输入
```

**讲解例子**

训练时看过很多猫狗图片；推理时判断一张没见过的图片。

**生图提示词**

```text
生成左右对比页。

左半部分标题“训练”，画面是一组多样化图片样本进入模型，像学生练习大量例题，但不要画幼稚卡通；
右半部分标题“推理”，画面是一张新图片进入同一个模型，模型给出新的判断结果。

主标题：
“训练像刷题，推理像考试”

左侧说明：
“从大量例子中学习规律”

右侧说明：
“用规律判断新的输入”

整体使用教学信息图，不出现复杂公式。
```

### 第 6 页：置信度和错误

**页面目标**

破除“AI 给出答案就一定正确”的误解。

**屏幕文字**

```text
92% 有把握，不等于 100% 正确

光线、角度、噪声、数据差异
都会影响判断
```

**互动**

问学生：“天气预报降雨概率 80%，结果没下雨，预报是不是完全没用？”

**生图提示词**

```text
生成一页关于 AI 不确定性的教学页。主要视觉是一张机器人视觉检测示例：正常光线下识别清晰，弱光和遮挡条件下识别框变得不稳定。旁边显示一个“92%”置信度仪表，但明确留有不确定区域。

标题：
“92% 有把握，不等于 100% 正确”

四个影响因素：
“光线”
“角度”
“噪声”
“数据差异”

底部结论：
“重要决定需要人来确认”

不要制造恐慌感，重点是科学理解概率。
```

**屏幕文字**

```text
会回答问题，还不等于会在现实中行动
```

**知识点**

聊天 AI 主要影响信息；机器人动作会影响真实世界。

**生图提示词**

```text

标题：
“会回答问题，还不等于会在现实中行动”

左侧关键词：
“文字输入 / 文字输出”

右侧关键词：
“感知环境 / 执行动作 / 接收反馈”

机器人造型现代、友好、可信，不要人形战斗机器人。
```

**生图提示词**

```text

“1 感知距离”
“2 判断危险”
“3 停止或转向”

标题：
“小车避障：请观察三个问题”

右侧问题：
“它看到了什么？”
“它怎样判断？”
“它做了什么？”

页面像实验课任务说明，不要画儿童玩具风。
```

### 第 11 页：演示复盘

**页面目标**

把实物现象上升成知识。

**屏幕文字**

```text
避障不是“聪明地绕开”

测量距离
→ 比较阈值
→ 改变电机动作
```

**讲解重点**

先用简单规则跑通闭环，再谈更复杂模型。

**生图提示词**

```text
生成小车避障原理页。横向流程：

超声波传感器测量“35 cm”
→ 判断“距离小于安全阈值”
→ 电机停止
→ 小车转向

标题：
“避障不是魔法，而是一条判断链”

底部结论：
“测量距离 → 比较阈值 → 改变动作”

使用简洁工程流程图，保留数字 35 cm 和安全阈值概念。
```

### 第 16 页：多模态判断

**页面目标**

```text
多个线索互相支持，判断才更可靠
```

- 动作速度下降。

**生图提示词**

### 第 18 页：核心案例

**页面目标**

让学生发现同一句话背后可能有不同原因。

**屏幕文字**

```text

机器人下一步应该做什么？
```

**可能原因**

- 没听懂。
- 任务太难。
- 已经疲劳。
- 感到烦躁。
- 身体不舒服。

**生图提示词**

```text
“我不会，我不想做了。”

周围以五条分支展示可能原因：

“没听懂”
“任务太难”
“已经疲劳”
“感到烦躁”
“身体不舒服”

标题：
“同一句话，可能对应不同问题”

底部问题：
“机器人下一步应该做什么？”

场景真实克制，不把学生画得幼稚或夸张。
```

### 第 19 页：安全响应等级

**页面目标**

建立机器人动作的风险分级。

**屏幕文字**

```text
状态不同，机器人的动作也不同
```

**三级处理**

- 低风险：解释、鼓励、简化。
- 中风险：暂停、保持距离、询问。
- 高风险：停止动作、通知老师。

**生图提示词**

```text
生成一个从低风险到高风险的三级阶梯图。

第一级，蓝色：
“困惑 / 注意力下降”
“重复说明、简化任务”

第二级，橙色：
“疲劳 / 烦躁”
“暂停、询问、保持距离”

第三级，红色但不过度警报化：
“疼痛 / 求助 / 摔倒风险”
“停止动作、通知老师”

标题：
“状态不同，机器人的动作也不同”

底部结论：
“风险越高，机器人越应该保守”
```

### 第 23 页：展示与评分

**页面目标**

**生图提示词**

## 六、任务卡印刷内容

### 任务卡 A：困惑还是受挫？

```text
学生连续三次没有完成动作，并说：“我不会。”

设计要求：
机器人如何判断他是没听懂、任务太难，还是不想继续？
机器人应该问什么？
是否需要降低任务难度？
```

### 任务卡 B：保持距离

```text
学生说：“别靠近我。”同时身体向后退。

设计要求：
机器人应该停止什么动作？
怎样保持安全距离？
什么时候需要请老师介入？
```

### 任务卡 C：疲劳

```text
学生动作速度持续下降，并说：“我今天好累。”

设计要求：
机器人需要观察哪些线索？
应该休息、降低任务量，还是继续鼓励？
如何向学生确认？
```

### 任务卡 D：安全信号

```text
学生突然说：“有点疼。”

设计要求：
机器人能否继续任务？
应该停止哪些动作？
怎样联系老师或护理人员？
```

### 任务卡 E：注意力下降

```text
学生长时间看向窗外，对机器人的提醒没有回应。

设计要求：
机器人如何判断他没听见、没听懂，还是注意力下降？
怎样重新吸引注意而不反复催促？
```

## 七、生图使用建议

1. 先把“统一视觉总提示词”发给 GPT，让它记住整套设计规则。
2. 每生成一页，再发送对应页面提示词。
3. 要求 GPT 每次只生成一张 16:9 页面，不生成多个备选拼图。
4. 中文文字尽量少。标题和复杂表格建议后期在 PowerPoint 中手动添加。
5. 如果人物或机器人造型变化太大，将第 1 页生成图作为后续页面的视觉参考图。
6. 第 10、13、14、17、20、24 页需要人物和机器人一致时，要明确说“延续第 1 页机器人和学生的造型”。
7. 第 22 页设计画布建议直接在 PowerPoint 里用形状绘制，不建议完全依赖生图文字。
