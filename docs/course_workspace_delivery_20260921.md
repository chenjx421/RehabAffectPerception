# 课堂复核与图文报告交付记录

日期：2026-09-21

后续进展：同日已补充同课多视频核准和趋势去重，详见 [同课多视频核准](batch_review_delivery_20260921.md)。以下为单视频工作区交付时的记录，课程批次功能以该后续说明为准。

## 本次可使用的流程

1. 教师登录，进入“课堂视频”。上传、处理及单帧身份确认沿用现有流程。
2. 在视频任务上选择“课堂复核与报告”，或进入 `/demo2/analysis` 选择自己的任务。
3. 群像概览只列出当前视频已绑定或有本任务观察记录的学生，不导入历史演示人物。
4. 在“片段复核”记录上课日期、目标、条件、达成标准、起止秒数、教师任务、学生回应、支持方式及可观察状态。
5. 四维分数可以留空。提供学习机会与有效观察次数后，由教师确认复核；满足现有量表条件才生成目标总分。
6. 保存后，群像、个体观察、图文报告与长期测量读取同一条版本化记录。支持编辑、回放和说明原因后撤销。
7. 下载独立 HTML 图文报告或 JSON 记录；打印时仅输出报告页，可在浏览器保存为 PDF。

## 已完成的实现

- 新增按上传任务隔离的课堂工作区与任务选择入口。教师只能读取自己的任务；管理员不从该接口获取学生个人观察原文。
- 群像展示关联学生数、复核目标数、可计分目标数和待处理记录；不把不同学生的个别化目标分数直接平均为教师成绩。
- 个体页显示目标分数、证据、提问、回应、支持与观察状态。没有证据的维度保持空缺。
- 视频复核保存时校验实际视频时长、原片可用性、当前帧版本、文件哈希和该学生在时段内的有效身份绑定。
- 观察记录保存身份绑定编号、源视频校验值与帧版本。身份被撤销或帧版本改变后，相关总分从新报告和趋势中排除，文字保留待重新确认。
- 报告为本地规则生成，不调用外部模型。本次合成验收正文为 1,063 字符，包含目标图表和文字说明；无有效证据时只出短缺项说明，不编造千字分析。
- 增加任务索引，读取当前视频的观察时不加载全校历史观察文本。
- 页面采用蓝白配色，桌面左侧导航，手机双列视图切换；窄屏表格在自身区域滚动。

## 验证与边界

- 后端、量表、入口等一次相关回归：273 通过，1 个旧管理员导航文案断言失败。按新的权限与导航设计更新断言后，针对本次修改的 57 项测试全部通过。
- 独立临时数据库、合成 H264/AAC 视频、真实 HTTP 接口及 Edge 浏览器验证，不替换 API 响应、不使用真实儿童数据。
- 验证保存、第二次修改、刷新读取版本、下载 HTML/JSON、打印 PDF、撤销记录，以及其他教师和管理员越权拒绝。
- 1440、390、320 像素宽度检查；最终截图无整页横向溢出，无浏览器脚本错误。
- 合成验收只证明软件链路，不证明学生识别准确率、教学效果或真实班级可用性。

## 下一步实施顺序

1. 明确课程批次、同课多视频、目标和学生的关联规则，再合并报告和观察次数。
2. 用已授权、教师标注的片段建立验证集。先接入语音转写及说话时段，再做人物持续跟踪和互动证据候选；系统提出候选，教师核准。
3. DeepSeek仅作为可选解释器：使用最小化的匿名结构化证据和已批准引用，校验数字与引用后交教师复核。不得自行改权重，不发送原始视频或诊断全文。本次未接通DeepSeek。
4. 完成存储生命周期、恢复演练、学校设备与网络试用后，再决定正式投放范围。
