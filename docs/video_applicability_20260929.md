# 视频适用性检查（人工确认版）

## 已实现

单课工作台新增视频适用性区。视频处理完成不等于具备特教评价资格，默认状态为待确认。系统自动检查处理状态、来源摘要、正时长和原片可用性；无音轨、低分辨率、明显偏暗采样帧给予工程提醒，不因这些指标给老师扣分。灰度、分辨率阈值未经过学校数据校准，也不用于识别课堂类别。

内容类型由授权上传教师人工选择：特教课堂、普通课堂、无关内容、无法判断、证据不足。确认特教课堂须填写目标或教案依据、回看依据，并勾选确认。系统不根据人脸判断障碍或特教身份，不把上传标题当作内容证明。

后端拦截未确认适用的视频评分和复核提交；允许保存无评分、未复核的观察草稿。已存观察保留，但无有效适用性确认时不参与当前视频报告、长期趋势或同课汇总计分。视频重处理或来源变更会使确认失效。已有合格确认且视频自然到期的历史人工观察不因到期自动删除或归零；到期视频不可新确认或新评分。

检查与确认写入本地数据库，保留版本、操作者和修改历史；账号和学校隔离。公网网关增加对应接口白名单，仍需邀请与账号鉴权。

## 不应对外声称的能力

尚无可靠的自动场景分类、影视或伪造内容检测、恶意上传检测。若使用者故意谎报内容并人工造假，本机制不能自动识破。因此这是“默认不出分 + 技术检查 + 人工适用性确认”，不是自动防作弊模型。普通课堂仍可查看媒体和通用观察，但暂未实现普通教育专用评分量表。

当前门控覆盖上传视频的学生测量、单课报告、长期趋势与同课汇总；独立的双轨课堂评价仍是手工录入评价，没有与上传视频自动绑定，不能宣传成所有评分入口均已完成自动审查。

## 后续

本次适用性、课堂分析、测量、多视频汇总和公网网关相关测试共102项通过。隔离浏览器验证待确认、无关视频、普通课堂、证据不足和特教人工确认切换、保存重开及320/390宽度布局；使用合成素材验证流程，不作为分类准确率实验。

在授权范围内建立课堂、普通课堂、无关活动、影视片段、黑屏和低质视频的独立测试集，再加入视觉语言模型的候选分类，输出置信度、片段证据和无法判断。模型只作候选筛选；须验证误拒、漏拒和教师复核成本后再启用自动拦截。无音轨不直接拒绝有效的非口语教学记录。
