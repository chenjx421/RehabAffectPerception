# 双轨课堂评价核对与实施方案

核对日期：2026-09-16。依据为本次提供的三份学校原表、当前代码和本地浏览器验收。当前可展示双轨规则、人工录入、证据解释与保存流程，不能宣称已实现视频自动科学评课、学科动态权重或经过验证的优越性。

## 三份学校材料的用途

1. 《课堂教学-基本评价指标》评价课堂教学质量。10项各1至10分，原始总分100分，四类占20%、30%、30%、20%；单项等第为A 9–10、B 6–8、C 3–5、D 1–2。另有总分乘70%、四舍五入保留一位的教学得分。当前代码保留原分、折算10分和70分制结果，未将项目6分线冒充学校正式合格标准。
2. 《课堂评价表》是15项试行课堂评价，A=5、B=4、C=3、D=2，综合为15项均分。原表列A 4.5–5、B 3.6–4.4、C 2.6–3.5、D 2.5以下；均分出现4.466…等值时如何舍入、边界是否含端点需校方确认。当前支持录入与原均分，不自动生成综合等第；尚未为该表建立增强映射。
3. 《二年级下学期生活语文-生活数学课程学习评价表》评价学生课程学习，不是课堂教师质量表。A/B/C是分层目标，1–5表示从完全达不到到完全达到；维度为兴趣、习惯、学习效果。学期目标（例如识字数量）不能用一节课视频判定。当前双轨课堂评价尚未接入这份表的逐项分层目标模型。

## 当前分数如何产生

基本表学校折算分为10个学校条目分的平均数。系统增强分为增强条目分乘权重后求和。增强的10项权重依次为15%、10%、8%、7%、5%、10%、10%、20%、8%、7%。两轨任何一项缺失，都不能形成该轨完整总分；不把未观察填零。

设学校条目分为s、增强条目分为z、校表权重为w、增强权重为v：证据分差=sum(w×(z−s))；权重分差=sum((v−w)×z)；两者相加就是总分差。该分解有固定顺序，是数值归因，不是教学因果证明。

截图合成案例：学校80/100，折算8.00/10，教学分56/70；增强7.57/10；总差−0.43，其中证据修正−0.20、权重变化−0.23。案例用于验证软件计算与界面，不代表真实学生、教师或课堂结果。

## 建议确认的正式设计

### 学校轨

保留学校原表及其版本，标明教师原始打分还是系统按校表初评。后续接入视频时，系统只为有证据的条目提出候选评分；内容正确性等需要教案、课程目标或专业审核的条目不能由人脸表情补齐。教师复核后形成正式校内记录。

### 系统增强轨

在共同的课堂质量维度下，增加回应机会覆盖、支持方式是否适宜、提示后的独立尝试、目标分层匹配、调整前后证据等指标。每个评分等级要有可操作的行为锚点，绑定片段、观察次数和支持条件。6分定义为达到课前约定的最低要求，不能以安静、目光接触或动作规范作为所有学生的统一门槛。

### 学科与个别化目标

课堂质量与学生五领域表现分别建模，不把学生能力较弱直接扣到教师总分。先按学校确认的五领域原名建映射表，再将本课目标对应到其中相关领域。语文关注沟通表达，数学关注数量概念与操作，体育关注动作目标与安全适配；未涉及的领域显示不适用。

课程权重应在课前选择并保存版本，展示与通用方案相比哪些条目增减及理由。先让教师审核候选配置，再做敏感性分析和真实课程校准；不要由LLM自由生成百分比。不同权重版本、不同目标口径的分数不直接连成同一趋势或排名。

## DeepSeek接入定位

建议接入“有证据可追溯的解释助手”，不承担科学认证或最终打分。调用链为：结构化课堂证据与教师复核 → 允许外发的字段白名单 → 本地批准的文献片段检索 → DeepSeek候选解释 → 数字与引用校验 → 教师审核与版本保存。

输入包括匿名课程类型、已确认目标、条目分、权重版本、证据编号、时间段及来源。输出采用固定JSON字段：事实证据编号、解释、改进建议、引用编号、不确定性。模型返回不存在的证据或引用，或更改分数，一律拒绝该输出并返回本地模板。原始学生视频、姓名、诊断、IEP原件不发送外部模型。

当前接口只完成了普通报告润色的配置入口，不能直接叫作这个Agent。现有代码需要补齐：自由文本脱敏、引用白名单、事实与数字校验、外发授权与审计、报告审核状态、超时降级；并修正旧的7000字最小返回门槛与当前千字报告要求的冲突。未完成这些条件前，不启用真实学生资料的外部调用。

## 科学验证方法

先由至少两名有特教经验的教师对同一批片段独立评分，明确分歧并修订评分锚点；报告条目加权Kappa或总分ICC及置信区间。再把课程按教师、学生或时间分组划分校准与保留验证集，不能让同一视频相邻片段分散到两边造成泄漏。

比较学校原轨、固定增强权重、学科候选权重三种方法；检查目标达成的一致性、证据覆盖、误报、漏报及建议可执行性。对不同支持需要、表达方式、课程类型分别检查偏差。权重做小范围扰动分析，查看结论是否轻易翻转；保留样本量、缺失比例、评分者分歧与不确定性。小样本只报告初步结果，不宣称普遍有效。
