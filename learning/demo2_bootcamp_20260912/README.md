# Demo2 实习项目三天学习包

代码核对日期：2026-09-12。对象：陈嘉鑫。以公司特殊教育课堂软件 Demo2 为主，不把个人 MuJoCo 预研混入公司成果。

## 学完的标准

你能独立讲解一条上传视频的完整处理路径，解释每个模型和算法，找到关键代码，复现小实验，并回答产品与算法的局限。三天按每天约4小时有效学习设计，共12小时，不包含休息。时间紧可以分成六个半天。三天不能替代系统学习深度学习，更不能保证掌握所有模型训练方法。

学习顺序：先读本页和 MODEL_CARDS.md，再配合 PPT 与 HANDBOOK.md。练习见 practice.py，个人进度写在 PROGRESS.md。真实学生资料不用于面试展示、公开仓库或外部模型请求。

每个知识块使用“直观解释、术语、项目代码、小问题、纠错”的顺序。每次只讲一个小主题，不连续输出一整天课程。你回答后再继续。一次不会不代表学不会，教师任务应换例子并给提示。

## 最先记住的事实

1. 人脸位置模型是 YuNet，固定权重文件 face_detection_yunet_2023mar.onnx，使用OpenCV DNN在CPU上推理。本项目没有重新训练它。
2. 姓名由教师与本校名册关联。当前未接入SFace、ArcFace等人脸身份匹配模型。
3. 短时位置建议是Shi–Tomasi角点与金字塔Lucas–Kanade光流，最多约5秒，跟丢后停止。它不是神经网络，也不是整课多目标跟踪。
4. FFmpeg处理视频和音轨。亮度、拉普拉斯方差、帧差、RMS都是计算指标，不是学情模型。
5. 新上传链路尚未接通中文ASR、可靠课堂状态模型和自动千字学情报告。旧演示规则的结果不能套给新课程。
6. 早期状态融合和平滑是规则。仓库里的DecisionTreeClassifier属于独立机器人策略实验，不属于当前学校视频分析主链路。未把VLA、PPO列为公司Demo成果。

## 运行练习

在项目根目录运行，默认实验只使用数学数字与合成数组，不接触真实数据库：

```powershell
& D:/anaconda3/python.exe learning/demo2_bootcamp_20260912/practice.py self-check
& D:/anaconda3/python.exe learning/demo2_bootcamp_20260912/practice.py model-info
```

可选：经授权的本地图片推理。它只输出候选框，不写文件、不保存身份、不调用外部服务。不要把输出附带的真实资料用于公开传播。

```powershell
& D:/anaconda3/python.exe learning/demo2_bootcamp_20260912/practice.py detect --image D:/path/to/authorized_image.jpg
```

所有演示账号、实际视频、原始IEP、密钥和数据库备份都不放入学习包。包里的PPT和笔记可以独立阅读，练习脚本需在原项目环境运行。
