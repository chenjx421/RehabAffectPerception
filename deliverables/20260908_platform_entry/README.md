# 课堂学习分析平台 入口页面与后续方案

本次完成用户与管理员登录分流、短账号别名、城市区县学校填写与保存、注册申请落库和后台查看。上传授权改为按钮确认，详情可展开，保留授权审计；长期归档默认关闭。

## 给领导看页面

- `login.html`：浏览器打开即可预览，账号和密码不会发送到后台。
- `register.html`、`privacy.html`：与登录页放在同一个目录，可点击跳转。
- `登录页面.png`：可直接转发的登录页截图。
- `学校选择.png`、`会员注册.png`：新入口截图，不包含真实学生资料。
- `课堂分析平台入口与后续开发方案.docx`：本次功能、市场参照、后续视频分析原型及公网部署条件。

## 本机实际操作

项目根目录双击 `start_school_demo2.cmd`，使用本机地址 `http://127.0.0.1:8791/demo2/login`。用户账号为 t1 至 t4，管理员为 admin。实际密码单独保存在项目 `.runtime/demo2_pilot_accounts_20260908.md`，不在此公开预览包中。

注册目前是开通申请。管理员可在后台查看申请信息，再通过项目方安排账号开通；未实现自助即时开通、自动通知或付费会员。

学校信息目前是账号的课程归属信息，并非已经实现完整跨学校租户体系。新上传视频仍以预检结果为主，后续真实视频分析见开发方案，不能将课例演示指标当作新视频结果。

完整源码与市场研究仍在原项目中。本包不含学生视频、档案、生产数据库或可用账号密码。
